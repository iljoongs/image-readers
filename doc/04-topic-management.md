# 04. 대주제/소주제 관리

## UI 구성
좌측 패널에 TreeView 형태로 대주제 > 소주제 계층 표시.
- 대주제 노드 클릭 → 하위 소주제 목록 펼침/표시
- 소주제 노드 클릭 → 우측 페이지 영역에 해당 이미지들 표시
- 우클릭 컨텍스트 메뉴: 대주제는 "소주제 추가", "평점 설정", "장르 설정", "썸네일 설정"(2026-10-18 추가, 2026-10-19 "커버 이미지 설정"에서 개명, 아래 "대주제 장르/썸네일" 참조), "이름변경", "삭제". 소주제는 "이름변경", "삭제". 홈 화면 카드의 우클릭 메뉴도 "소주제 추가"만 빠진 동일한 메뉴다(`07-ui-layout.md` "홈 화면").
- 목록 하단에 **정렬 토글 버튼 2개**: "이름 정렬"과 "평점 정렬"(2026-09-16 추가), 각각 독립적으로 오름차순/내림차순을 전환한다.
  - **이름 정렬**: 대주제 목록과 각 대주제의 소주제 목록 모두에 적용된다. 정렬은 자연 정렬(natural sort)을 사용해 이름에 포함된 숫자를 실제 값으로 비교한다 (예: "1화" < "2화" < "10화"). 상세는 `03-data-storage.md`의 "이미지 파일 불러오기" 참조.
  - **평점 정렬**: 평점(아래 "대주제 평점")은 대주제에만 있는 값이라 **대주제 목록에만** 적용된다(각 대주제 하위 소주제 목록은 영향받지 않음). 값이 같으면 이름(자연 정렬)으로 2차 정렬한다.
  - 두 버튼 중 **마지막으로 누른 쪽**이 "현재 정렬 기준"이 된다: 대주제 추가, 이름변경, 평점 변경 시 그 기준으로 대주제 목록 위치가 다시 맞춰진다. 소주제 추가/이름변경은 항상 이름 기준으로 재배치된다(소주제는 평점 기준 정렬 대상이 아니므로).

## 대주제 평점 (2026-09-14 추가)
- 대주제는 트리에서 **progress bar 모양** 안에 이름이 표시된다: 채움 정도와 채움 색이 평점(1~10) 값에 따라 정해진다. 이건 "읽던 위치"(소주제의 `ProgressLabel`, 읽기 진행 상황)와는 다른 개념으로, 사용자가 직접 매기는 평점이다. 상세 표시 방식은 `07-ui-layout.md`의 "좌측 패널" 참조.
- 새 대주제의 기본 평점은 1이다.
- 우클릭 메뉴 "평점 설정" → 대화상자(슬라이더, 1~10)로 값을 바꾼다. 앱 종료 시 대주제 이름을 키로 하여 설정 파일에 저장되고, 다음 실행 시 복원된다(`02-architecture.md` "세션 상태 저장/복원"). 대주제 이름을 변경하면 키가 달라져 기존 기록이 끊기는 건 `TopicProgress`(읽던 위치 기록)와 동일한 알려진 제약이다.

## 대주제 장르/썸네일 (2026-10-18 추가, 2026-10-19 "커버 이미지"→"썸네일" 용어 정정 + 드래그 앤 드롭 지정 추가)
홈 화면 카드(`07-ui-layout.md` "홈 화면")에 쓰이는 두 값. 둘 다 소주제는 사용하지 않고, 위 평점과 동일하게 대주제 이름을 키로 설정 파일에 저장되어 다음 실행 시 복원된다.
- **장르**: 우클릭 메뉴 "장르 설정" → 미리 정의된 목록(드라마/판타지/액션/로맨스/일상/개그/미스터리/순정/스포츠/스릴러/무협/학원/공포/스토리, sample.png 상단 탭에서 따옴)에서 복수 선택. "/"로 이어붙여 저장·표시한다(예: "판타지/액션"). 기본값은 미지정(빈 문자열). 이름 변경 시 끊기는 제약이 있다(평점과 동일).
- **썸네일**: 지정하는 방법은 두 가지다 — ① 우클릭 메뉴 "썸네일 설정" → 파일 선택 대화상자로 이미지 파일을 고른다. ② 홈 화면 **카드 전체**(썸네일 그림뿐 아니라 제목/장르/화수 텍스트 영역과 그 사이 여백까지) 위로 이미지를 **드래그 앤 드롭**한다(2026-10-19 추가, game-platform 프로젝트의 `Card_DragOver`/`Card_Drop` 방식을 그대로 가져옴 — `DragDropImageHelper`). 로컬 파일뿐 아니라 웹 브라우저에서 드래그한 이미지(URL, `data:` URI, 렌더링된 비트맵, 그리고 아래의 "가상 파일")도 받는다.
  - 카드 루트 `Border`에 `Background="Transparent"`를 명시해야 한다 — WPF의 `Border`/`Panel`은 `Background`가 `null`이면 자식이 덮지 않은 빈 영역에서 히트테스트가 안 돼 그 부분에 드롭(또는 클릭)해도 반응하지 않는다(2026-10-19 수정 — 처음 포팅할 때 이 설정을 빠뜨려서 썸네일 그림 바깥 영역에 드롭하면 조용히 무시됐다). game-platform 카드의 `Border.Style`에도 동일하게 `Background="Transparent"`가 있다.
  - **Microsoft Edge/Chrome에서 웹 이미지를 드래그하면 URL 텍스트 형식 없이 "가상 파일"(`FileGroupDescriptor`/`FileContents`)만 제공하는 경우가 많다**(2026-10-19 수정 — 사용자가 Edge에서 드래그했는데 안 된다고 리포트해서 발견). game-platform의 `DragDropImageHelper`에는 이 처리가 없어서, 이 앱이 이미지 추가 드래그드롭(`05-image-features.md`)에 이미 쓰고 있던 `VirtualFileDropReader`를 가져와 `DragDropImageHelper`에 추가로 연결했다 — URL 텍스트 추출/자체 다운로드보다 먼저 시도한다(브라우저가 이미 받아온 실제 픽셀이라 핫링크 차단 등으로 실패할 일이 적다).
  - 둘 다 원본 파일 위치와 무관하게 유지되도록 `%APPDATA%\ImageTopicViewer\thumbnails\{대주제 이름}.original{확장자}`로 복사해 보관한다(`ThumbnailStore`, game-platform 프로젝트의 `ThumbnailHelper`와 동일한 저장 방식 — `02-architecture.md` 참조).
  - 지정 전에는 홈 화면에 연회색 placeholder가 보인다. 자동으로 소주제 이미지를 가져오지는 않는다 — 항상 사용자가 직접 고르거나 드래그해야 한다.
  - **예외적으로 대주제 이름을 바꾸면 썸네일 파일도 같이 옮겨지므로 끊기지 않는다**(파일명 자체가 대주제 이름이라 가능 — 아래 "대주제 이름 변경" 참조).

## 추가
- **대주제 추가**: 트리 최상단에서 "대주제 추가" → 이름 입력 → `.data/{이름}/` 폴더 생성
- **소주제 추가**: 대주제 선택 후 "소주제 추가" → 이름 입력 → `.data/{대주제}/{소주제}/` 폴더 생성 (빈 폴더)
- 신규 소주제 선택 시 우측은 빈 페이지 상태로 시작 (이미지 없음 안내 표시)
- 앱이 "소주제 추가"로 만드는 것은 항상 **폴더**다. 압축(`.zip`) 소주제는 앱이 만들지 않고, 사용자가 직접 파일을 넣으면 인식한다 (`03-data-storage.md`의 "압축 파일 기반 소주제" 참조).

## 삭제
- 대주제/소주제 삭제 시 확인 다이얼로그 표시 ("하위 이미지가 모두 삭제됩니다. 계속하시겠습니까?")
- 확인 시 해당 폴더(또는 압축 소주제의 경우 `.zip` 파일)를 **Windows 휴지통으로 이동**한다(영구 삭제 아님, 사용자가 실수해도 복구 가능). 하위 소주제/이미지 포함.

## 이름변경 (Cascading 처리 — 핵심 로직)
파일명 규칙이 `대주제_소주제_번호` 형태이므로, 이름 변경 시 다음을 함께 처리해야 한다.

### 소주제 이름 변경
- **폴더 기반**:
  1. 폴더명 변경: `.data/{대주제}/{기존소주제}/` → `.data/{대주제}/{새소주제}/`
  2. 폴더 내 모든 파일명의 prefix를 `{대주제}_{새소주제}_{번호}`로 재작성
- **압축(.zip) 기반**: `.zip` 파일명만 바꾼다 (`{기존소주제}.zip` → `{새소주제}.zip`). 내부 이미지 파일명은 번호만 쓰므로 다시 쓸 게 없다.

### 대주제 이름 변경
1. 폴더명 변경: `.data/{기존대주제}/` → `.data/{새대주제}/`
2. 하위 모든 **폴더 기반** 소주제 내 파일명의 prefix를 `{새대주제}_{소주제}_{번호}`로 일괄 재작성 (압축 기반 소주제는 내부 파일명이 번호만이라 건너뜀)
3. 썸네일이 지정되어 있으면(위 "대주제 장르/썸네일") `thumbnails/{기존대주제}.original{확장자}`를 `thumbnails/{새대주제}.original{확장자}`로 함께 옮긴다(`ThumbnailStore.Rename`).

### 이름 유효성 검증
- 빈 문자열 불가
- Windows 폴더/파일명 금지 문자 불가: `\ / : * ? " < > |`
- 이름 끝에 마침표(`.`)나 공백 불가 (Windows 폴더명 제약)
- Windows 예약 장치 이름 불가(대소문자 무관): `CON`, `PRN`, `AUX`, `NUL`, `COM1`~`COM9`, `LPT1`~`LPT9`
- 동일 계층에서 이름 중복 불가 (같은 대주제 하위에 동일한 소주제명 존재 불가) — 폴더와 `.zip` 파일이 같은 이름 공간을 공유한다 (예: 폴더 "10화"와 `10화.zip`은 공존 불가).
