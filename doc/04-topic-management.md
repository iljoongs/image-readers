# 04. 대주제/소주제 관리

## UI 구성
좌측 패널에 TreeView 형태로 대주제 > 소주제 계층 표시.
- 대주제 노드 클릭 → 하위 소주제 목록 펼침/표시
- 소주제 노드 클릭 → 우측 페이지 영역에 해당 이미지들 표시
- 우클릭 컨텍스트 메뉴: "추가", "삭제", "이름변경"

## 추가
- **대주제 추가**: 트리 최상단에서 "대주제 추가" → 이름 입력 → `.data/{이름}/` 폴더 생성
- **소주제 추가**: 대주제 선택 후 "소주제 추가" → 이름 입력 → `.data/{대주제}/{소주제}/` 폴더 생성 (빈 폴더)
- 신규 소주제 선택 시 우측은 빈 페이지 상태로 시작 (이미지 없음 안내 표시)

## 삭제
- 대주제/소주제 삭제 시 확인 다이얼로그 표시 ("하위 이미지가 모두 삭제됩니다. 계속하시겠습니까?")
- 확인 시 해당 폴더 전체를 **Windows 휴지통으로 이동**한다(영구 삭제 아님, 사용자가 실수해도 복구 가능). 하위 소주제/이미지 포함.

## 이름변경 (Cascading 처리 — 핵심 로직)
파일명 규칙이 `대주제_소주제_번호` 형태이므로, 이름 변경 시 다음을 함께 처리해야 한다.

### 소주제 이름 변경
1. 폴더명 변경: `.data/{대주제}/{기존소주제}/` → `.data/{대주제}/{새소주제}/`
2. 폴더 내 모든 파일명의 prefix를 `{대주제}_{새소주제}_{번호}`로 재작성

### 대주제 이름 변경
1. 폴더명 변경: `.data/{기존대주제}/` → `.data/{새대주제}/`
2. 하위 모든 소주제 폴더 내 파일명의 prefix를 `{새대주제}_{소주제}_{번호}`로 일괄 재작성 (소주제 개수만큼 반복)

### 이름 유효성 검증
- 빈 문자열 불가
- Windows 폴더/파일명 금지 문자 불가: `\ / : * ? " < > |`
- 이름 끝에 마침표(`.`)나 공백 불가 (Windows 폴더명 제약)
- Windows 예약 장치 이름 불가(대소문자 무관): `CON`, `PRN`, `AUX`, `NUL`, `COM1`~`COM9`, `LPT1`~`LPT9`
- 동일 계층에서 이름 중복 불가 (같은 대주제 하위에 동일한 소주제명 존재 불가)
