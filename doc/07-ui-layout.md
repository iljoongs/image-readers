# 07. UI 레이아웃

## 전체 화면 구성
```
┌─────────────────────────────────────────────┐
│  상단 툴바: [연속보기 | 단일보기]              │
├───────────────┬───────────────────────────────┤
│               │                               │
│  좌측 패널     │        메인 이미지 영역         │
│  (주제 트리)   │   (연속보기 or 단일보기)         │
│               │                               │
│  대주제1       │                               │
│   ├ 소주제1    │                               │
│   └ 소주제2    │                               │
│  대주제2       │                               │
│   └ 소주제1    │                               │
│               │                               │
└───────────────┴───────────────────────────────┘
```

## 좌측 패널
- TreeView, 폭 조절 가능(GridSplitter)
- 하단 또는 우클릭 메뉴에 "대주제 추가" 버튼
- 각 노드 우클릭: 추가/삭제/이름변경

## 메인 영역
- 연속보기: ScrollViewer + ItemsControl(이미지 목록)
- 단일보기: 단일 Image 컨트롤 + 좌/우 클릭 영역(투명 오버레이 or Grid 2분할)
- 선택된 소주제가 없을 때: 안내 문구 표시 ("좌측에서 주제를 선택하세요")
- 선택된 소주제에 이미지가 없을 때: "이미지를 여기로 드래그하세요" 안내 표시 + 드롭 가능 영역 표시

## 스타일
- 별도 지정 없으면 WPF 기본 스타일 사용, 추후 필요시 테마 적용 검토
