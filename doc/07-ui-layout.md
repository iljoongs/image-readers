# 07. UI 레이아웃

## 전체 화면 구성
```
┌─────────────────────────────────────────────┐
│  상단 툴바: [N/max]  [연속|단일 전환]  [크기 %]  │
├───────────────┬───────────────────────────────┤
│               │                               │
│  좌측 패널     │        메인 이미지 영역         │
│  (주제 트리)   │   (연속보기 or 단일보기)         │
│               │                               │
│  대주제1       │                               │
│   ├ 소주제1(3/10)│                             │
│   └ 소주제2    │                               │
│  대주제2       │                               │
│   └ 소주제1    │                               │
│               │                               │
└───────────────┴───────────────────────────────┘
```

## 좌측 패널
- TreeView, 폭 조절 가능(GridSplitter)
- 하단 또는 우클릭 메뉴에 "대주제 추가" 버튼
- 각 노드 우클릭: 추가/삭제/이름변경
- **읽었던 위치 표시** (2026-08-27 추가): 한 번이라도 열어본 소주제는 이름 옆에 `(마지막으로 보던 이미지 번호/전체 이미지 수)`를 회색으로 표시한다. 1부터 시작하는 번호를 쓴다. 열어본 적 없는 소주제는 아무것도 표시하지 않는다. 앱 종료 시 저장되어 재실행 후에도 유지된다 (상세는 `02-architecture.md`의 "세션 상태 저장/복원" 참조). 이름 변경 시 이 기록의 키가 바뀌어 끊길 수 있다(세션 복원의 마지막 선택 주제 복원과 동일한 제약).

## 상단 툴바
- **현재 페이지 번호 표시/입력란**: 툴바 맨 앞. `(N/전체)` 형태, N은 1부터 시작하며 텍스트박스라 직접 입력해 그 번호로 이동할 수 있다. `06-view-modes.md`의 "현재 페이지 번호" 참조.
- 연속보기/단일보기 전환 버튼(토글)
- **크기 콤보박스**: 이미지 표시 배율(%) 선택 — 10%~250%, 10% 단위, 100%가 원본 크기. `06-view-modes.md`의 "확대/축소" 참조.
- **맨 위로 / 맨 아래로 버튼**: 연속보기에서 페이지 스크롤을 맨 위/맨 아래로 이동. 단일보기에서는 숨김(의미가 없으므로).
- **스크롤 속도 콤보박스**: 연속보기 마우스 휠 스크롤 배속(x1~x5) 선택. 단일보기에서는 숨김. `06-view-modes.md`의 "연속보기" 참조.
- 앱 이름(ImageTopicViewer) 텍스트는 표시하지 않는다 (타이틀바에 이미 표시되므로).

## 메인 영역
- 연속보기: ScrollViewer(세로+가로 모두 스크롤 가능) + ItemsControl(이미지 목록)
- 단일보기: 단일 Image 컨트롤 + 좌/우 클릭 영역(투명 오버레이 or Grid 2분할)
- 선택된 소주제가 없을 때: 안내 문구 표시 ("좌측에서 주제를 선택하세요")
- 선택된 소주제에 이미지가 없을 때: "이미지를 여기로 드래그하세요" 안내 표시 + **페이지 전체 영역**이 드롭 가능해야 한다(안내 문구 자체의 좁은 영역이 아니라 연속보기/단일보기 화면 전체).

## 스타일
- 별도 지정 없으면 WPF 기본 스타일 사용, 추후 필요시 테마 적용 검토
- 단일보기 배경은 흰색.

## 창 상태 복원
- 창 위치/크기/최대화 여부는 종료 시 저장되어 재실행 시 복원된다. 상세는 `02-architecture.md`의 "세션 상태 저장/복원" 참조.
- 창 타이틀바에는 현재 뷰 모드가 함께 표시된다 (예: `ImageTopicViewer (연속보기)`).
