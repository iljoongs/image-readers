# 01. 프로젝트 개요

## 목적
사용자가 이미지를 주제(대주제 > 소주제)별로 분류하여 저장하고, 순서대로 열람할 수 있는 로컬 데스크톱 도구.

## v1 범위 (Scope)
포함:
- 대주제/소주제 트리 UI (추가/삭제/이름변경)
- 신규 소주제 생성 시 빈 페이지에서 시작
- 이미지 드래그드롭으로 추가 (원본 파일은 이동, 삭제됨)
- 페이지 내 이미지 드래그드롭으로 순서 변경
- .data 폴더 기반 저장 (대주제/소주제별 폴더 분리)
- 파일명 규칙: `대주제_소주제_번호(000)` 형태로 순차 넘버링
- 순서 변경 시 파일명 재넘버링
- 연속보기 / 단일보기 모드 전환 (상단 툴바)
- 단일보기: 화면 좌/우 클릭으로 이전/다음 이미지 이동

제외(v1 범위 아님, 필요시 추후 논의):
- 클라우드 동기화
- 이미지 편집(크롭/회전 등)
- 다중 이미지 동시 드래그
- 검색/태그 기능
- 슬라이드쇼 자동재생

## 사용자 시나리오 예시
1. 사용자가 좌측 트리에서 "여행" 대주제를 선택한다.
2. 하위 소주제 목록이 표시된다. "제주도"를 선택한다.
3. 우측 페이지 영역에 저장된 이미지들이 순서대로 표시된다.
4. 새 이미지를 탐색기에서 드래그해서 페이지에 놓으면 파일이 `.data/여행/제주도/` 폴더로 이동되고 목록 끝에 추가된다.
5. 이미지 순서를 드래그로 바꾸면 해당 폴더의 파일명이 순서에 맞게 재정렬된다.
6. 상단 툴바에서 "단일보기"로 전환하면 화면 중앙 기준 좌/우 클릭으로 이미지를 넘겨볼 수 있다.
