# 06. 뷰 모드

## 모드 전환
상단 툴바에 토글 버튼(또는 라디오 버튼) 배치: **연속보기** / **단일보기**

## 연속보기 (Continuous)
- 선택된 소주제의 모든 이미지를 세로로 스크롤하며 연속 표시.
- 이미지 순서는 파일명 번호 순서를 따름.
- 스크롤 위치는 소주제 전환 시 초기화.

## 단일보기 (Single)
- 한 번에 하나의 이미지만 화면 중앙에 표시.
- 화면을 좌/우 절반으로 나누어 클릭 영역으로 이동 처리:
  - **왼쪽 절반 클릭** → 이전 이미지 (뒤로가기)
  - **오른쪽 절반 클릭** → 다음 이미지 (앞으로가기)
- 첫 이미지에서 이전 클릭, 마지막 이미지에서 다음 클릭 시 동작 없음(또는 순환 여부는 `08-open-decisions.md`에서 결정).
- 마우스 커서가 좌/우 영역에 있을 때 방향을 암시하는 시각적 힌트(화살표 아이콘 등) 표시 권장.

## 공통
- 모드 전환 시 현재 보고 있던 이미지 위치(인덱스)를 최대한 유지.
