# 06. 뷰 모드

## 모드 전환
상단 툴바에 토글 버튼(또는 라디오 버튼) 배치: **연속보기** / **단일보기**

## 연속보기 (Continuous)
- 선택된 소주제의 모든 이미지를 세로로 스크롤하며 연속 표시.
- 이미지 순서는 파일명 번호 순서를 따름.
- 스크롤 위치는 소주제 전환 시 맨 위로 초기화.
- 상단 툴바의 **맨 위로 / 맨 아래로** 버튼으로 즉시 이동 가능.
- **스크롤 속도**: 상단 툴바 콤보박스에서 x1(기본)~x10 배속 선택 가능(1 단위, 2026-09-22 x5→x10로 확대). 마우스 휠 한 칸당 기본(x1) 48px(WPF 기본 스크롤 3줄 x 16px)을 배속만큼 곱한 만큼 이동한다. 선택한 배속은 앱 종료 시 저장되어 다음 실행 시 복원된다(`02-architecture.md` "세션 상태 저장/복원").

## 단일보기 (Single)
- 한 번에 하나의 이미지만 화면 중앙에 표시.
- 화면을 좌/우 절반으로 나누어 클릭 영역으로 이동 처리:
  - **왼쪽 절반 클릭** → 이전 이미지 (뒤로가기)
  - **오른쪽 절반 클릭** → 다음 이미지 (앞으로가기)
- 첫 이미지에서 이전, 마지막 이미지에서 다음 시도 시 **순환하지 않고 동작 없음**(정지).
- 소주제 전환 시 맨 앞(첫 번째) 이미지로 초기화.
- 키보드 **←/→ 방향키**로도 이전/다음 이미지 이동을 지원한다(클릭과 동일한 정지 규칙 적용).
- **마우스 휠**로도 이전/다음 이미지 이동을 지원한다: 휠을 위로 굴리면 이전, 아래로 굴리면 다음 (클릭/방향키와 동일한 정지 규칙 적용).
- 마우스 커서가 좌/우 영역에 있을 때 방향을 암시하는 시각적 힌트(화살표 아이콘 등) 표시 권장.

## 확대/축소 (연속보기·단일보기 공통, 2026-08-27 갱신 — px 방식을 % 방식으로 대체, 2026-10-24 Microsoft Edge 방식으로 전면 교체)
- 이미지 표시 배율을 **%**로 조절한다. 2026-10-24부터 **Microsoft Edge/Chrome과 동일한 단계 목록**을 쓴다 — 25/33/50/67/75/80/90/**100(기본)**/110/125/150/175/200/250/300/400/500%(`Services/EdgeZoomLevels.cs`, 홈 화면 카드 확대축소와 공유 — `07-ui-layout.md` "홈 화면"). 예전의 10%~250%, 10% 단위 목록은 버렸다.
- **100%는 이미지의 실제 픽셀 해상도가 아니라, 표시 폭 800px 기준값**이다(다른 %는 이 800px에 비례해서 커지고 작아진다: `표시폭 = 800px × 퍼센트 / 100`). 스캔본마다 실제 해상도가 제각각이라 "100% = 원본 해상도 그대로"로 하면 이미지가 창보다 훨씬 크거나 작게 나오는 문제가 있어(2026-08-27 버그 수정) 이 방식을 쓴다.
- **조절 방법은 Ctrl + 마우스 휠뿐이다**(2026-10-24 — 예전에 있던 "크기" 콤보박스는 제거했다. Microsoft Edge도 배율 선택 목록을 상시 노출하지 않고 Ctrl+휠/단축키로만 조절하는 것과 동일). 휠 한 칸에 위 단계 목록을 따라 한 단계씩 이동(원본을 넘어서는 순환 없음, 25%/500%에서 멈춤).
- **확대/축소 팝업**(2026-10-24 추가): Ctrl+휠로 배율을 바꾸면 Microsoft Edge처럼 화면 상단 가운데에 `[-] {배율}% [+]` 팝업이 잠깐 떠서(어두운 반투명 알약 모양) 현재 배율을 보여준다. 팝업의 `-`/`+` 버튼을 직접 눌러도 조절된다. 조작이 없으면 1.5초 뒤 사라진다(`ContinuousPageViewModel.IsZoomIndicatorVisible`, `07-ui-layout.md` "메인 영역").
- 기본값은 100%(원본 크기).
- 연속보기에서 Ctrl 없이 휠을 굴리면 기존과 동일하게 페이지 스크롤.
- 앱 종료 시 마지막 배율을 저장했다가 재실행 시 복원한다. 예전 버전(10%~250%, 10% 단위)에서 복원된 값이 새 단계 목록에 정확히 없으면, 다음 Ctrl+휠 조작 시 그보다 크거나 같은 가장 가까운 단계로 스냅한 뒤 이동한다(`EdgeZoomLevels.Step`).

## 현재 페이지 번호 (2026-08-27 추가)
- 상단 툴바 맨 앞에 **현재 보고 있는 이미지 번호 / 전체 이미지 수**를 `(N/max)` 형태로 표시한다. 번호는 **1부터 시작**한다.
- 번호는 텍스트박스로 되어 있어 직접 입력해 수정할 수 있다. 값을 입력하고 Enter를 누르면 그 번호의 이미지로 이동한다(연속보기면 해당 위치로 스크롤, 단일보기면 해당 이미지로 전환). 범위를 벗어난 값은 1~전체 범위로 자동 보정된다.
- 소주제가 선택되지 않았거나 이미지가 없으면 표시하지 않는다.

## 공통
- 모드 전환 시 현재 보고 있던 이미지 위치(인덱스)를 최대한 유지.
- 앱 종료 시 마지막 뷰 모드와 스크롤/이미지 인덱스 위치를 저장했다가 재실행 시 복원한다. 단, 같은 세션 내에서 다른 소주제로 전환할 때는 스크롤 위치가 초기화되는 기존 규칙이 그대로 적용된다. (상세는 `02-architecture.md`의 "세션 상태 저장/복원" 참조)
- 창 타이틀바에 현재 뷰 모드를 표시한다: 예) `ImageTopicViewer (연속보기)` / `ImageTopicViewer (단일보기)`.
