# 08. 미결정 항목 / 향후 확장 아이디어

이 문서의 항목들은 아직 확정되지 않았습니다. 구현 중 해당 사항이 나오면 **임의로 결정하지 말고 사용자에게 확인**하세요.

## 미결정 항목

- [x] 단일보기 모드에서 마지막/첫 이미지 도달 시 순환(loop) 여부
- [x] 단일보기 모드 키보드 방향키(←/→) 지원 여부
- [x] 이미지가 많을 경우(수백 장 이상) 썸네일 캐싱/비동기 로딩 적용 여부
- [x] 대량 재넘버링 시 성능 최적화 필요 여부 (v1은 단순 구현 우선)
- [x] 이미지 삭제(개별 이미지 삭제) 기능 포함 여부 — 현재 계획에는 명시적으로 없음
- [x] 지원 이미지 포맷 최종 확정 (`03-data-storage.md`의 1차 제안 목록 검토)
- [x] 다중 이미지 동시 드래그 시 개별 순서 지정 필요 여부

## 향후 확장 아이디어 (v1 이후)

- 슬라이드쇼 자동재생
- 이미지 간단 편집(회전, 크롭)
- 주제/이미지 검색
- 태그 기반 분류
- 클라우드 백업/동기화
