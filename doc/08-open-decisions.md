# 08. 미결정 항목 / 향후 확장 아이디어

이 문서의 항목들은 아직 확정되지 않았습니다. 구현 중 해당 사항이 나오면 **임의로 결정하지 말고 사용자에게 확인**하세요.

## 결정된 항목 (2026-08-23)

- [x] **데이터 폴더 위치**: 실행 폴더/프로젝트 폴더 고정이 아니라 **사용자가 최초 실행 시 지정**. 경로는 `%APPDATA%\ImageTopicViewer\settings.json`에 저장, 설정에서 변경 가능(변경 시 기존 데이터는 이동하지 않고 새 폴더는 빈 상태로 시작). → `02-architecture.md`, `03-data-storage.md` 반영 완료.
- [x] **단일보기 순환 여부**: 순환하지 않음. 첫/마지막 이미지에서 정지(동작 없음). → `06-view-modes.md` 반영 완료.
- [x] **단일보기 키보드 방향키(←/→) 지원**: 지원함. → `06-view-modes.md` 반영 완료.
- [x] **개별 이미지 삭제 기능**: v1에 포함. 우클릭 메뉴/Delete 키로 삭제, 삭제 후 재넘버링. → `01-overview.md`, `05-image-features.md` 반영 완료.
- [x] **대량 재넘버링 성능 최적화**: v1에서는 최적화하지 않고 단순 구현(전체 재넘버링) 우선. 성능 이슈 발생 시 추후 검토. → `03-data-storage.md`에 이미 명시됨.
- [x] **다중 이미지 동시 드래그 시 개별 순서 지정**: v1 미지원. 드롭 순서대로 끝에 순차 추가만 지원. → `05-image-features.md`에 이미 명시됨.

## 미결정 항목 (제안된 기본값 — 사용자 확인 대기)

- [ ] 이미지가 많을 경우(수백 장 이상) 썸네일 캐싱/비동기 로딩 적용 여부
      - 제안 기본값: v1에서는 비동기 로딩만 적용하고 별도 썸네일 캐싱은 생략. 체감 성능 이슈 발생 시 추후 캐싱 도입 검토.
- [ ] 지원 이미지 포맷 최종 확정 (`03-data-storage.md`의 1차 제안 목록 검토)
      - 제안 기본값: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.gif`, `.webp` 목록을 그대로 최종 확정.

## 향후 확장 아이디어 (v1 이후)

- 슬라이드쇼 자동재생
- 이미지 간단 편집(회전, 크롭)
- 주제/이미지 검색
- 태그 기반 분류
- 클라우드 백업/동기화
